# US Stocks — Trailing P/E + Classic PEG

Weekly screen of NYSE/NASDAQ/AMEX common stocks.

**Filter:** `0 < Classic PEG < 2` (Finviz / Lynch-style PEG).

**Columns:** Ticker, Name, Exchange, Sector, Industry, Price, Market_Cap_B, PE_TTM, Classic_PEG.

Classic PEG is Finviz PEG (typically forward P/E ÷ expected next-5-year EPS growth).
PE_TTM is trailing twelve-month P/E.

PEG_TTM_growth is no longer published here. It is not Lynch PEG.

Latest snapshot (13 Sep 2026): 1,191 names pass; 1,029 also have trailing P/E > 0; median classic PEG 0.88; median trailing P/E 22.8.
